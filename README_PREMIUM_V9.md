# HaViQuant Premium V9

This package is a cleaned, end-to-end copy of the supplied HaViQuant v8 source with a premium institutional dark UI layer.

## Included
- Existing market-data, technical-analysis, decision, company-intelligence, portfolio, opportunity, backtesting and evidence modules.
- Premium forced-dark Streamlit theme that remains dark even when macOS/browser uses light mode.
- Large Plotly technical chart.
- Chart ranges: 1D, 5D, 1M, 3M, 6M, 1Y, 5Y.
- Dynamic ticker input.
- Live refresh controls.
- Defensive Company Intelligence rendering for dict/string records.
- SciPy dependency included.
- `.venv`, Python caches and macOS metadata are intentionally excluded.

## Run
```bash
cd ~/Downloads/HaViQuant_complete_premium_v9
./run_haviquant.sh
```

Open:
http://localhost:8501

If the terminal is running, keep it open. Do not paste the shell prompt itself into the terminal.
